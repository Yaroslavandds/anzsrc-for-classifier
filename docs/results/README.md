# Звіти скриптів

Знімки JSON-звітів, які записали скрипти з [training/](../../training/) під час роботи (з них узято всі цифри
документації). Локальні шляхи замінено на відносні; решта без змін. Метрики на val у звітах кроку 4 —
позафолдові.

| Файл | Що в ньому |
|---|---|
| `00_env.json` | обладнання, версії пакетів, довжина текстів у токенах, пробні кроки навчання на ноутбуці |
| `01_split.json` | параметри поділу, джерела, поділені за записами, розміри частин, рідкісні групи, перевірки |
| `02_baseline.json`, `02_baseline_clean.json` | TF-IDF + логістична регресія: метрики на val загалом, за походженням і за групами |
| `03_<модель>.json` | трансформери: параметри запуску, метрики після кожної епохи, пам'ять відеокарти, час |
| `04_ensemble.json` | перше поєднання (TF-IDF + SPECTER2) |
| `04_ensemble_clean.json` | поєднання на очищених мітках (TF-IDF + SPECTER2 + RoBERTa-base) |
| `04_ensemble_large.json` | п'ять моделей, разом з усією сіткою ваг |
| `04_ensemble_final.json` | підсумкове поєднання (TF-IDF + SPECTER2 + ModernBERT-large) |
| `05_test*.json` | оцінка на test: усі моделі поєднання, попередні системи, за походженням, 213 груп, найчастіші сплутування |
| `06_clean_labels.json` | очищення міток train: скільки змінено й виключено, журнали, групи, що змінилися найбільше |
| `extra_bootstrap_ci.json` | бутстреп за джерелами: 95 % інтервали P@1 і топ-3, різниці між системами (частки, не відсотки; останнє число — частка повторів, де різниця ≤ 0) |
| `extra_confidence_mode.json` | режим впевненості: пороги й крива «частка записів — точність» |
| `extra_single_models_test.json` | окремі моделі на test (зокрема SciBERT, якої немає у звітах кроку 5) |
